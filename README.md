# Scripture Voice

**Scripture Voice** is an offline-capable, installable PWA Bible audio podcast, study, and devotional reader designed to run **100% on local Bible text, static artwork, and your device's built-in voice synthesis**—with **zero runtime LLM, cloud TTS, translation, or image generation API calls**.

## Key Features

- **Zero Runtime AI or Network Dependencies**: All pre-seeded Bible passages, multi-length devotionals (`1`, `3`, `5`, `10`, `15` min), worship song lyrics, classical oil-painting plates, book plates, and search indexes load directly from static files in `public/data/` and `src/assets/images/`.
- **66-Book Numbered Canonical Sidebar**: Browse all Old and New Testament books numbered `1`–`66` with explicit chapter counts, localized names, chapter grids, and Old/New Testament tabs.
- **Client-Side BM25 & Voice Search**: Query keywords, themes (`"Comfort in anxiety"`, `"焦慮中的安慰"`), or scripture references (`"John 3:16"`, `"約翰福音 3:16"`) instantaneously against per-book and full-Bible search indexes (including CJK character/bigram tokenization). Includes optional microphone search via the browser Web Speech API configured to the active language's BCP-47 tag.
- **On-Device OS Voice Reading**: Reads localized scripture verses, devotional commentary, and worship lyrics aloud in real time using your operating system and browser's built-in **Web Speech Synthesis (`window.speechSynthesis`)** matched to the active locale (`en-US`, `zh-TW`, `zh-CN`, etc.), with narrator timbre tuning (`Fenrir`, `Kore`, `Puck`, `Charon`, `Zephyr`), playback speed control (`0.85×`–`1.3×`), live spoken subtitles, and Media Session lock-screen controls—requiring zero pre-generated `.wav` or `.mp3` audio files.
- **Installable PWA & iPhone Home Screen Support**: Powered by `vite-plugin-pwa` (Workbox) in `vite.config.ts` with precached app shell, manifest, SVG book plates, and runtime caching for chapter data and fonts. Supports native install prompts on Chromium/Android and guided **Safari → Share → Add to Home Screen** installation on iPhone/iPad, plus an automatic offline status banner.
- **Persistent Preferences, History & Exports**: Saves reading history and study preferences (`lang`, `voice`, `devotionalLength`) in `localStorage`. Includes a direct **Download PDF** button (`下载 PDF` / `下載 PDF`) and **Share / Export** menu supporting rich-text + image clipboard copy, plain text copy, Web Share API sharing, and printable PDF study sheets via `html2canvas` and `jspdf`.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server** (port `3000`):
   ```bash
   npm run dev
   ```

3. **Type-check & build for production**:
   ```bash
   npm run lint
   npm run build
   ```

4. **Preview the production PWA & test offline mode locally**:
   ```bash
   npm run preview
   ```
   Open DevTools → Application → Service Workers (or toggle Offline) to verify full offline caching against the production bundle.

## Installing on iPhone / Android / Desktop

- **iPhone / iPad (Safari)**: Open the deployed HTTPS site in Safari, tap the **Add to Home** button (or Safari's **Share** icon), and choose **Add to Home Screen**. Once added, the app opens full-screen using `apple-touch-icon.png` and cached offline bundles.
- **Desktop / Android (Chrome / Edge)**: Click **Install App** in the top header when prompted by the browser.

## Expanding the Local Dataset & Pre-Generation Pipeline

All static JSON bundles under `public/data/` are compiled at build time by `scripts/pregenerate.ts`. **No LLM, API key, or tokens are used**—the script combines curated chapters from `SEEDED_CORPUS` (`src/data/seededCorpus.ts`) with a built-in public-domain crawler (`bible.helloao.org`) and local cache (`scripts/.cache/`):

```bash
# Re-generate all seeded + previously crawled chapters for default languages (en, zh, zh-CN)
npm run pregenerate

# Generate extra languages (or all 11 supported languages) on demand
npm run pregenerate -- --langs=es,fr,ja
npm run pregenerate -- --langs=all

# Crawl and pre-generate Chapter 1 of all 66 Bible books + flagship chapters
npm run pregenerate -- --all-books

# Crawl and pre-generate >=50% of all 27 New Testament books in Chinese
npm run pregenerate -- --nt-half --langs=zh,zh-CN

# Auto-crawl and pre-generate any canonical chapter (e.g. Ezra 2)
npm run pregenerate -- --chapters=ezra_2

# Auto-crawl an entire book by slug or book number (1-66)
npm run pregenerate -- --book=ezra
npm run pregenerate -- --book=24 chapter=all

# Auto-crawl the entire 66-book, 1,189-chapter public-domain Bible into static offline bundles
npm run pregenerate -- --all-canon --langs=en,zh,zh-CN

# Re-build offline purely from local cache without network access
npm run pregenerate -- --chapters=ezra_2 --no-crawl
```

> **Per-Book Command Reference**: See [`PREGENERATE_66_BOOKS.md`](./PREGENERATE_66_BOOKS.md) for all **66 individual `npm run pregenerate -- --book=<slug>` commands** (Genesis through Revelation).

Any newly crawled chapter is **merged into `public/data/index.json`** (without erasing existing chapters), cached locally in `scripts/.cache/`, and automatically highlighted in the sidebar.

### Public-Domain Bible Text & JSON Sources

To expand beyond the 10 flagship chapters (for example, to import `ezra_2` or all 1,189 chapters at build time), you can download public-domain Bible text from these repositories and archives:

- **Ready-to-Use JSON Repositories & Keyless Endpoints**:
  - **Free Use Bible API (`https://bible.helloao.org`)**: Keyless static JSON over HTTPS for hundreds of public-domain translations (including World English Bible and Chinese Union Version).
  - **`thiagobodruk/bible` (`https://github.com/thiagobodruk/bible`)**: Uniformly structured JSON and XML files across 140+ versions and 85 languages (KJV, Chinese CUV, Spanish Reina-Valera, etc.).
  - **`scrollmapper/bible_databases` (`https://github.com/scrollmapper/bible_databases`)**: Multi-format public-domain Bible datasets (JSON, SQLite, CSV, XML) with cross-references.
  - **`TehShrike/world-english-bible` (`https://github.com/TehShrike/world-english-bible`)**: Standalone per-book JSON files for the World English Bible (WEB).
- **Primary Source Archives**:
  - **eBible.org (`https://ebible.org`)**: Authoritative public-domain archives for the World English Bible (`ebible.org/web/`) and Traditional/Simplified Chinese Union Version (`cmn-cu89t` / `cmn-cu89s`) in USFM/USFX and text formats.
  - **Bible-API.com (`https://bible-api.com`)**: Keyless single-passage JSON lookups by reference (e.g., `https://bible-api.com/ezra+2?translation=web`).

### Adding More Chapters or UI Languages

1. **Scripture, Devotionals & Lyrics**: Add public-domain verses, devotionals, and song lyrics to `src/data/seededCorpus.ts` (and optionally register new keys in `FEATURED_CHAPTER_KEYS` inside `src/data/bibleBooks.ts`), or adapt `scripts/pregenerate.ts` to read downloaded JSON files from the sources above.
2. **Artwork**: Place classical illustration plates in `src/assets/images/` and register them in `CHAPTER_ARTWORK_MAP` inside `src/data/bibleBooks.ts` (plus localized captions in `src/data/uiStrings.ts`).
3. **UI Localization**: Add translations to `src/data/uiStrings.ts` for any additional `SupportedLang` codes.
4. **Rebuild Static Bundles**: Run `npm run pregenerate` to regenerate:
   - `public/data/books-manifest.json` & `public/data/books/{book}.json` (lazy-loaded per-book search & index bundles)
   - `public/data/index.json` (TF-IDF / BM25 full search index)
   - `public/data/bible/{lang}/{book}_{chapter}.json`
   - `public/data/devotionals/{lang}/{book}_{chapter}.json`
   - `public/data/lyrics/{lang}/{book}_{chapter}.json`

## Project Architecture Note

- **Zero Runtime APIs**: No file in `src/` imports `@google/genai`, runs an Express backend, or calls external AI/TTS endpoints (`@google/genai`, `express`, and `dotenv` in `package.json` are unused starter template dependencies).
- **PWA Assets**: Manifest icons (`public/icon.svg`, `public/apple-touch-icon.png`, `public/pwa-192x192.png`, `public/pwa-512x512.png`, `public/pwa-maskable-512x512.png`) and Workbox caching rules are configured in `vite.config.ts` and registered in `src/main.tsx`.
